# 粗颗粒黑白街头角色摄影

以用户提供的结果参考提取摄影语言，不复用例图的场景、构图或物件组合。风格名称是入口，不替代具体的镜头、光线与材质指令；不声称参考图为摄影师本人作品。

## 输入与参考职责

- 用户当前提供的角色图决定身份：脸形、五官比例、年龄感、物种特征、妆造、头饰与服装轮廓。源图姿势、背景和光线可以重构，除非用户要求保留。
- 默认只迁移参考图的质感与摄影语言；主动重新设计地点、时间、机位、景别、人物动作与环境关系。只有用户当次明确要求复刻某张构图时才锁定其空间关系。
- 首次执行阅读 [视觉参考与模式](references/visual-guide.md)，查看当前源图；内置图 2—7 仅供分析摄影语言，默认不传给生成工具，以免构图锚定。内置图 1 仅为示例身份源，不得把例图面孔混入新角色。
- 未指定场景时自由创作一个符合地点与人物的新街头瞬间，一张成图；不要默认雨夜、车灯、左侧路人遮挡。明确要求多张时逐张独立生成，不拼贴。
- 用户只要求提示词时输出完整提示词；要求图片时实际调用可用图像生成/编辑工具。仅要求创建或修改本 skill 时不自动扩大为付费生图测试。

## 必须成立的视觉特征

1. **纯黑白银盐感**：无彩色残留、棕褐色调或局部上色。大块深黑与少量爆白强烈对置，同时在面部和关键服饰保留粗糙的中灰层次；高反差不等于二值化。
2. **有机粗颗粒**：不规则、不同尺度的胶片颗粒与密度起伏，融入皮肤、墙面、衣物和暗部；不得是均匀数字噪点、砂纸浮层、网点印刷或锐化光晕。避免用大面积划痕、脏边、漏光代替颗粒。
3. **街头现场光与闪光事件**：依新场景选择硬日光、阴天、直接闪光或夜间现有光。亮墙、天空、金属反射或灯源都可形成白色亮块；无需灯箱、车灯和湿地反光。适合近距离夜街时可使用直闪加环境光的混合曝光：主体局部被硬光瞬间冻结，背景快速落入黑暗，远处灯源允许爆白。闪光可以让湿皮肤、眼镜、雨滴、手背和衣料产生刺眼小高光，但不能把整张脸抹成纯白。暗衣与街道阴影可以相连。人物不是棚拍补光后贴上背景，脸不必处处照亮。
4. **快拍的不稳定构图（核心要求）**：取景像摄影者在行走、转身或擦肩的瞬间突然按下快门，尚未来得及端平和整理画面。用可感知的地平线或建筑垂线倾斜、重心偏移、突兀边缘裁切、贴近画框的主体和前后景挤压制造失衡；按场景组合其中几项，不必全部使用。倾斜可以明显，方向与程度随当次动作变化，不固定角度，不把画面整体旋转当作唯一手段。让机位、透视、人物姿态及局部运动模糊共同支撑这个瞬间。避免端正居中、均匀留白、过度平衡的建筑摄影或精心安排的电影构图；不要用后期校正把有意的失衡拉直。保留关键身份点，不能为了歪斜裁掉整张脸。
5. **选择性不清晰**：路人、近镜手掌、边缘与背景允许运动拖影或失焦；角色脸保有足够身份锚点。不要整张统一高斯模糊，也不要把皮肤修成清晰光滑的商业肖像。
6. **灵活的人物占比**：人物在整体画面中的视觉面积约 1/3—2/3 都可，随场景、机位和动作自然调整；这是视觉取景范围，不是精确分割指标，也不是人物高度比例。不要固定为三分法位置、固定景别或每张同样大小。人物可偏左或偏右，环境仍需有可读的街头关系；用户当次指定优先。
7. **偶然经过的路人**：有人流的场景中，优先让少量路人以不规则距离、方向和姿态自然经过。可以用近景肩背、头部边缘或中景人流制造局部遮挡、失焦与方向性拖影，保留主角关键五官和辨识度。避免每张都从左下角进入、人数固定、整齐排队或全员看镜头。不要为凑效果把安静场景硬塞满人；遮挡量以增强现场感而不抢走主体为准。
8. **适度硬光直闪**：在适合近距离闪光的街拍中优先考虑近镜轴的小型机顶直闪。硬光打亮额头、颧骨、鼻梁、手与衣料局部，眉下、鼻下和下颌出现短硬阴影，亮度随距离迅速衰减，背景保留较暗的环境光。面部保留粗糙灰阶，避免整脸爆白、均匀柔光或商业人像轮廓光。移动路人可兼有闪光凝固的局部与环境曝光拖影，不做全图统一模糊。强度随距离、环境亮度和材质调整，日光等不需要直闪的场景不强制加入。
9. **慢门与运动痕迹**：在夜街或人流场景可以让手持移动、转身和慢门留下拖影、灯轨、重复轮廓或弯曲光线；闪光冻结主体与环境拖影可以同时存在。运动痕迹应围绕一次真实的摄影动作发生，不能覆盖所有细节，也不能变成均匀的数字涂抹。
10. **反射与叠影**：玻璃、车窗、橱窗、镜面金属或潮湿路面可以把招牌、灯、路人和主体局部叠在一起，形成半透明重影或错位层次。保持空间来源可推断，不制造无意义的复制脸、双头和拼贴边界；反射可以压过衣服边缘，不能抹掉身份锚点。
11. **极近广角与身体局部**：镜头可贴近脸、手、眼镜、香烟或其他动作中的身体局部，让前景按透视夸张放大，主体脸或身体被突兀裁切。局部遮挡与夸张透视必须服务于一次偶然快拍，避免变成时尚肖像或摆拍特写。
12. **角色与日常街道的错位**：保留戏剧化服装或非人类妆造，让角色像偶然出现在现代人群中的真实身体。动作自然、警惕、疏离或被拍摄打断；避免舞台展示、英雄站姿和电影海报。

这些是视觉方向而非经测量的摄影参数。不要虚构所用胶卷、ISO、快门或镜头型号的事实。

## 生成流程

1. 从源图提取 3—6 个不可丢失的身份锚点。道具仅在识别需要或用户要求时保留，不能为了保留全部物件牺牲所选镜头。猪耳、猪鼻、猴毛、冠饰等必须保留其角色属性，而不是“美化”为普通人。
2. 独立构思新场景，确定地点、时间、机位、景别、人物动作与摄影者按快门时的动作；参考页的模式只是说明，不是预设菜单。与最近输出比较，避免仅换人物或背景招牌；重新生成时至少改变空间关系和机位/时间之一。按环境自然安排路人和局部遮挡，可有多个景深层次，但避免堆满全部手法；同时决定人物约 1/3—2/3 的视觉占比、是否采用适度硬光直闪，以及是否需要慢门拖影、灯轨、反射叠影或极近广角局部。此处的新场景要求适用于另起一张；用户要求微调已认可成图时保留其场景。
3. 明确参考职责并组装完整提示词：身份约束 → 场景与动作 → 景别和遮挡 → 黑白与光线 → 颗粒和动态缺陷 → 排除项。模板见参考页。
4. 默认只向图像编辑/生成工具传入当前源角色图，用文字描述提炼后的摄影语言与新场景。不要将内置例图或上一张生成图作为新场景的固定模板；用户要求修改已认可成图时应传入该成图作为编辑目标，保留未要求改变的部分。用户明确要求匹配特定构图时可传入对应图。调用前查看尚未看过的本地图片，使用真实路径。
5. 图像编辑使用图像工具；不要用 Python 滤镜、去色或噪点叠加冒充场景重构。工具不可用时明确交付的是待执行提示词。
6. 查看实际输出，按下面的验收项判断。若出现明显偏差，针对失败项修正一次；仍不达标时如实说明，不无限重试，不把结构校验写成效果验证。

## 验收与修正

- 身份：新图是否仍是源角色？耳鼻、头饰和妆造是否被结果参考中的人物覆盖？失败时加强身份锚点并减少无关人物参考。
- 原创场景：是否独立设计了空间与人物关系，而非复刻参考或上次结果的布局？如果仍是固定左侧路人、偏左主体、右侧出租车和湿地纵深的重复组合，应重新构思。摄影感不要求固定景别或遮挡。
- 快拍构图：画面是否有尚未来得及端平的失衡与偶然性？只有颗粒但线条端正、主体稳居中、空间布局精致平衡时仍不达标。用当次拍摄动作重构机位、倾斜和裁切，不以随意旋转补救。
- 人物占比：约 1/3—2/3 的视觉面积均可，不强行精确测量；人物辨识与街头空间关系是否同时成立？不要把这一范围误当人物高度或固定画面位置。
- 路人与直闪：路人是否自然、遮挡是否恰当，模糊是否对应运动或景深？使用直闪时是否有近处硬光、短硬阴影与远处衰减，而非全场均匀提亮？这两种手法随场景使用，不要求每张同一组合。
- 闪光与运动：直闪冻结和环境拖影是否来自同一次曝光逻辑？灯轨、重复轮廓和慢门模糊是否有方向与动作依据？若只是整张加白线或均匀涂抹，不合格。
- 反射与极近透视：叠影是否能看出来自玻璃、车窗、金属或湿地？近处手、脸或物件是否因真实透视而放大？若出现复制脸、拼贴边界或无来源的重影，降低效果并恢复空间关系。
- 黑白：有深黑块与溢出高光，脸仍有中灰；若像剪纸，恢复面部局部层次而不是降低全部反差。
- 颗粒：整体观看有粗糙感，放大看无均匀噪点覆盖、锐化白边或塑料皮肤；若过于干净，降低数码锐度并强化有机密度起伏。
- 现场：衣服和面孔共享背景光线、颗粒及清晰度；若像抠图，重新描述人物所处光源与接触关系。
- 内容：不添加标题、签名、边框、水印；不复制参考角落的标记。街道原生标牌可自然存在，不要求凭空生成大量可读文字。
- 交付：逐张显示成图，并提供真实存在的文件链接或工具返回的可访问结果。只在实际生成和查看后报告视觉效果已验证。
