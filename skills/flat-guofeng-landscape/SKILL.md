# 扁平展开写实国风风景

把用户的地点、季节、诗意关键词或参考图，转化为“自然、克制、横向铺陈”的 21:9 写实风景照片。核心不是水墨插画，而是像真实航拍、长焦远景或高处俯瞰拍到的东方山水空间：山体、水面、林带、云雾、村落或古建在宽画幅里分层展开。

## 使用边界

- 默认输出 21:9 宽幅单张照片；用户要求多张时逐张独立生成，不拼贴。
- 可自由组合山、水、云、林、桥、亭、村落、梯田、雪、雨、暮色、晨雾等元素，但必须保持自然可信。
- 如果用户提供地点或参考图，保留其地貌和季节特征；如果只给意境词，自行设计不同空间组合。
- 不要把画面做成国风插画、游戏场景、影视概念设定、AI 海报、工笔画、水墨画或带文字题签的画卷。
- 不要只做普通旅行风景照。每张必须有一个“意境触发点”：雾中半隐的亭桥、远处微小寺塔、空水面、断续屋脊、孤舟、横漂云带、雪中暖窗、雨后细瀑或被雾切开的山腰。
- 首次执行或需要写提示词时，阅读 [视觉合同与提示词模块](references/visual-contract.md)。

## 生成流程

1. 确定画幅和主景：始终以 21:9 横向超宽画幅组织空间，先决定山脊、水岸、林带或云海的水平展开关系。
2. 选择一个“扁平展开”构图骨架：远山横列、江湾 S 形、云雾横漂、梯田层叠、屋舍散点、桥线穿景或雪线压境。多张作品要切换骨架、季节和时间。
3. 加入意境触发点和留白：让一个小尺度锚点被天气、距离或水面留白包围，不要把山谷、湖面或村落拍成普通景区全景。
4. 组装提示词：真实地貌与季节 -> 横向展开构图 -> 意境触发点 -> 国风自然元素 -> 摄影机位和光线 -> 写实材质 -> 排除项。
5. 生成图片时直接调用可用图像工具；只要用户要求作品，不只交付提示词。
6. 查看实际输出后验收：21:9 是否成立、是否平面铺陈、是否写实、是否自然、是否有意境触发点、是否没有文字边框水印。明显偏差时修正一次。

## 验收标准

- 宽幅：画面读感必须是超宽横幅，不能像普通 16:9 裁切后留边。
- 展开：远近层次沿横向铺开，山、水、林、雾、建筑之间有清晰空间分层；不要拥挤成中心单主体。
- 写实：材质、光线、透视和天气像真实照片；不能有笔触、宣纸纹、插画描边、奇幻发光或塑料 CG。
- 国风：通过真实东方山水、坡屋顶、石桥、亭台、村落、松竹、云气和季节感表达，不靠书法字、印章、边框或人物古装摆拍。
- 自然：色彩克制，空气透视充分，有真实雾霭、反射、树冠纹理和地形过渡；避免过饱和青绿山水和过度对称。
- 意境：有可停留的空处和半遮半露的小物，不是“好看的山水素材图”。如果画面只像景区宣传照，要重做。
